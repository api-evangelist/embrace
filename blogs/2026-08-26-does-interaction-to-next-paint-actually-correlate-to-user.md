Earlier this year, Google announced that Interaction to Next Paint (INP) is no longer an experimental metric. INP will replace First Input Delay (FID) as a Core Web Vital in March of 2024. Now that INP has arrived to dethrone FID as the responsiveness metric in Core Web Vitals , we’ve turned our eye to scrutinizing its effectiveness.
