# Embrace

> Embrace is a user-focused observability platform for mobile and web applications, built on
> OpenTelemetry. Its SDKs for iOS, Android, React Native, Flutter, Unity and the browser capture
> session, crash, exception, log, trace and network telemetry from real users. Programmatic
> access is a Prometheus-compatible Metrics API queried with PromQL, a REST Custom Metrics API,
> OTLP forwarding to third-party destinations, outgoing alert webhooks, and a hosted Model
> Context Protocol server exposing 21 read tools to AI assistants.
>
> Generated by API Evangelist on 2026-08-12. Embrace does not publish an llms.txt of its own
> (https://embrace.io/llms.txt returns 404), and publishes no OpenAPI document.

## APIs

- [Embrace Metrics API](https://embrace.io/docs/metrics-forwarding/metrics-api/): PromQL over the Prometheus HTTP API at https://api.embrace.io/metrics (regional: api-us1 / api-eu1). Bearer token from Settings → Organization → API.
- [Embrace Custom Metrics API](https://embrace.io/docs/metrics-forwarding/custom-metrics/custom-metrics-api/): create, get and delete custom metrics at https://api.embrace.io/custom-metrics/api/v1/app/{app_id}/custom-metrics. Token issued by an Embrace onboarding specialist.
- [Embrace MCP Server](https://embrace.io/docs/mcp/): Streamable HTTP MCP at https://mcp.embrace.io/mcp. OAuth 2.0 + PKCE or an emb_sa_ service-account bearer token with mcp:tools:call.

## Agent surface

- MCP endpoint: https://mcp.embrace.io/mcp
- OAuth authorization server metadata: https://mcp.embrace.io/.well-known/oauth-authorization-server
- OAuth protected resource metadata: https://mcp.embrace.io/.well-known/oauth-protected-resource
- Scopes: mcp:tools:call (required), mcp:read, mcp:write
- Tools: list_apps, get_app_details, get_top_versions, list_crashes, get_crash_details, get_crash_distribution, get_crash_stack_samples, list_exceptions, get_exception_details, list_logs, get_log_details, get_log_distribution, get_session_distribution, list_root_spans, get_root_span_distribution, list_network_domains, list_network_endpoints, get_network_endpoint_errors, get_network_endpoint_latency, get_network_endpoint_timeseries, get_network_endpoint_breakdown
- No A2A agent card is served on any Embrace host.
